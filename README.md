
# HatuaYako - Adulting 101: The Complete Playbook

**Hatua yako inayofuata inaanzia hapa.**

*Your next step starts here.*

## About the Project

Hatua is a  website designed to help young adults navigate the transition into independent living with confidence. It provides practical guidance on everyday life skills, helping users make informed decisions as they take their next steps toward adulthood.

From managing money to navigating Nairobi, Hatua makes adulting less overwhelming by breaking down important life skills into accessible topics and practical resources relevant to everyday life in Kenya.

## Project Goals

- Help young adults develop practical life skills.
- Make essential adulting information easy to understand.
- Encourage independence, confidence, and informed decision-making.
- Provide useful, Kenya-focused information for everyday challenges.
- Create an engaging and user-friendly learning experience.

## Features

### 1. Home Page
Introduces Hatua and guides visitors toward useful topics and resources.

### 2. Explore Topics
Provides a central place for users to discover information about different aspects of adult life.

### 3. Money Management
Covers essential financial skills, including:
- Budgeting and saving.
- Banking basics.
- M-Pesa and everyday financial transactions.
- Basic personal financial management.

### 4. Navigate Nairobi
Helps users understand how to get around Nairobi with confidence, including public transport and fare information.

### 5. Moving Out
Provides practical guidance to help young adults prepare for independent living, understand their responsibilities, and make informed decisions.

### 6. Build My Plan
Encourages users to identify where they are in their journey and take practical steps toward their personal goals.

### 7. Interactive User Interface
Includes image slideshows, animated statistics, interactive cards, hover effects, and scrolling content to make the website more engaging.
### 8. 	Work
 Provide knowledge on getting jobs, internships, freelancing, CVs, portfolios, interviews and workplace basics.

## Getting Started

### View the Live Website

Visit Hatua here:

[Open Hatua Website](https://tamilakaranja.github.io/Module-1-project/index.html)

### Run the Project Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/tamilakaranja/Module-1-project.git
   ```

2. Navigate to the project directory:

  bash
   cd Module-1-project
   

3. Open the project folder in Visual Studio Code.

4. Open `index.html` in your browser, or use the Live Server extension in VS Code to preview the website.

## Target Audience

Hatua is designed primarily for young adults who want to develop practical life skills, become more independent, and navigate everyday responsibilities with confidence.

The website is especially relevant to young people in Kenya who are preparing for adulthood and learning to manage real world situations.

## Project Purpose

Hatua demonstrates how web development can be used to create an accessible digital resource that supports learning, independence, and personal growth.

It combines information architecture, visual design, and interactive web elements to make essential life skills easier to discover and understand.
